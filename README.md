# Контрольная работа №2

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта
Учебный интернет-магазин "Rick Owens Shop", разработанный с использованием CSS-фреймворка Bootstrap 5.3.

## Используемый фреймворк
Bootstrap 5.3 (подключен через CDN).

## Структура проекта
- `index.html` – главная страница (hero-блок, преимущества, товары);
- `catalog.html` – каталог товаров с модальным окном;
- `product.html` – страница товара (характеристики, вкладки, аккордеон);
- `order.html` – форма заявки;
- `css/custom.css` – минимальные кастомные стили;
- `README.md` – описание проекта.

## Реализованные компоненты Bootstrap
- `navbar` (адаптивная навигация);
- `card` (карточки товаров);
- `btn` (кнопки, варианты dark/outline);
- `badge` (значки статусов товаров);
- `alert` (информационные сообщения);
- `modal` (модальное окно быстрой заявки);
- `form-control`, `form-select`, `input-group`, `form-check` (формы);
- `accordion` (частые вопросы на странице товара);
- `tabs` (вкладки с описанием на странице товара).

## Самостоятельные доработки
В проект добавлены:
1. Компонент `tabs` (вкладки) на странице товара для структурирования информации.
2. Единый визуальный стиль (темная тема, кнопки `btn-dark`), соответствующий эстетике бренда.
3. Кастомные стили-заглушки для изображений (`.placeholder-image`).
